# Retail Store Sales Data Analysis

## Project Overview
This project focuses on performing hands-on data analysis using Python and Jupyter Notebook. The Retail Store Sales dataset is used to understand sales patterns, clean data, perform data manipulation, apply statistical analysis, and create visualizations.

## Dataset Information
- Dataset: Retail Store Sales – Dirty for Data Cleaning
- Source: Kaggle
- Original dataset: 12,575 rows and 11 columns
- An additional column, `Total Sales`, was created during analysis.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives
1. Set up the Python data science environment.
2. Import and explore the dataset.
3. Perform data manipulation using Pandas.
4. Clean missing values and duplicate records.
5. Create five types of visualizations.
6. Perform statistical analysis and exploratory data analysis.

## Data Cleaning
- Identified missing values.
- Checked duplicate records.
- Filled missing text values with `Unknown`.
- Filled missing numerical values using the median.
- Converted Transaction Date into datetime format.
- Verified the cleaned dataset.

## Data Manipulation
- Column selection
- Data filtering
- Sorting
- Grouping
- Creating a derived Total Sales column
- Category-level aggregation and merging

## Visualizations
1. Bar Chart – Total Sales by Category
2. Histogram – Distribution of Total Sales
3. Line Chart – Monthly Sales Trend
4. Scatter Plot – Quantity vs Total Spent
5. Box Plot – Total Sales Distribution

## Key Findings
- Total Sales: 1,604,609
- Average Sales: 127.60
- Total Transactions: 12,575
- Best Selling Category by quantity: Food
- Highest Sales Category by value: Butchers
- Average Quantity: 5.56
